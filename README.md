# SQE-Library-Management-System
Python-based Library Management System developed for Software Quality Engineering (SQE) Lab Assignment. The project includes system development, manual testing, unit testing, bug reporting, code quality analysis using SonarQube, security analysis using Snyk, and version control using GitHub.
# Library Management System

## Project Description
This project is a Python-based Library Management System developed for Software Quality Engineering (SQE). The system allows users to manage library books efficiently.

## Features
- Add Book
- View Books
- Search Book
- Issue Book
- Return Book
- File Handling for Data Storage

## Technologies Used
- Python
- GitHub
- SonarQube
- Snyk
- unittest

## Testing
The project includes:
- Manual Testing
- Automated Unit Testing using unittest

## Security Analysis
Security analysis was performed using Snyk.

## Code Quality Analysis
Code quality analysis was performed using SonarQube.

## How to Run
```bash
python main.py
```
